Cấu Hình Đường Dẫn Google Apps Script

Nhập Web App URL mà bạn thu được sau khi Deploy Google Apps Script dưới dạng Web App (Quyền truy cập: Anyone/Bất kỳ ai).

💡 Lưu ý: Nếu chưa có URL, bạn bấm vào nút "Mã Google Script" ở góc trên bên phải để xem hướng dẫn tạo trong 1 phút!

Mã Google Apps Script & Hướng Dẫn Cấu Hình Sheet

  1. Mở file Google Sheet của bạn -> Chọn Extensions (Tiện ích mở rộng) -> Apps Script.
  2. Xóa toàn bộ code cũ và dán đoạn code dưới đây vào file Code.gs:
  1. Nhấp vào nút Deploy (Triển khai) -> New deployment (Triển khai mới).
  2. Chọn loại Web App. Cấu hình:
    • Execute as: Me (Tôi)
    • Who has access: Anyone (Bất kỳ ai)
  3. Bấm Deploy, cấp quyền truy cập Google Account, sau đó copy lấy Web App URL dán vào phần cấu hình của app này!
